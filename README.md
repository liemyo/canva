# Amatu Design

Editor desain grafis di browser — media sosial, presentasi, poster, logo, dokumen — dengan template, foto, ikon, efek teks, animasi, dan alat AI. Tema liquid glass terang/gelap.

**Buka:** https://liemyo.github.io/canva/

## Fitur

- **Beranda**: pencarian, 36 ukuran siap pakai + ukuran khusus (px/mm/cm/in), desain terbaru, galeri template, Brand Kit, Proyek (bintang, salin, ganti nama, impor).
- **Editor**: multi-halaman, seret/ubah ukuran/putar dengan garis bantu magnet, pilih banyak (marquee/Shift), grup, kunci, lapisan, rata & beri jarak, salin/tempel gaya, undo/redo, zoom, tampilan kisi halaman, catatan pembicara.
- **Elemen**: 40+ bentuk, garis & panah, bingkai foto, kisi kolase, mockup perangkat, grafik data (batang, garis, area, pai, donat, progres), tabel, ikon & stiker (Iconify), foto (Lorem Picsum + Openverse).
- **Teks**: 100+ Google Fonts, kombinasi font, efek (bayangan, angkat, berongga, sambung, garis tepi, gema, glitch, neon, latar, gradasi), teks melengkung, daftar.
- **Foto**: 18 filter, penyesuaian (kecerahan, kontras, saturasi, suhu, rona, pudar, vinyet, blur), pangkas, bentuk/mask, bayangan, hapus latar AI di perangkat.
- **Animasi & presentasi**: 13 animasi elemen, animasi halaman, transisi, presentasi layar penuh dengan putar otomatis, timer, dan catatan.
- **Aplikasi**: kode QR, barcode, palet dari foto, ubah ukuran ajaib, teks ke gambar & tulis ajaib (AI), menggambar bebas.
- **Ekspor**: PNG (transparan), JPG, PDF standar/cetak, SVG, PowerPoint, file proyek `.amatu`, tautan salinan, salin gambar.
- **Alat gratis di beranda**: hapus latar, editor foto, kolase, konversi/kompres gambar, gambar ke PDF, palet warna, kombinasi font.

Semua desain dan unggahan tersimpan di IndexedDB browser (perangkat ini). Fitur AI gambar/teks memakai kunci Pollinations milik pengguna sendiri (disimpan lokal).

Kode: ES modules tanpa build — `index.html`, `css/`, `js/`.
